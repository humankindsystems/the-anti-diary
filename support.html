purchases

Unlimited Saved Entries and the Unsent Pack are optional one-time purchases.

If you previously purchased an upgrade using the same Apple ID, open the anti-diary and go to Settings → Purchases → Restore Purchases.

saved entries lock

Saved Entries can be protected using Face ID, Touch ID, the iPhone passcode, a custom PIN, or a password.

If you forget a custom PIN or password, device ownership must be confirmed using iPhone device security before the lock can be reset. If device authentication is unavailable, enable a device passcode in iPhone Settings before attempting recovery.

unsent

Messages, emails, and voicemails created inside the Unsent Pack are designed for private release. They are not delivered to the person or recipient entered in the app.
